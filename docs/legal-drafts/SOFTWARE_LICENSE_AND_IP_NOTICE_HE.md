# הודעת רישיון תוכנה וקניין רוחני — SafeDoc
> תאריך: 2026-07-18 | גרסה: 1.0 | סיווג: פנימי + לקוחות

## 1. בעלות על הקוד

מערכת SafeDoc, לרבות כל הקוד המקור, העיצוב, הממשק, מבנה הנתונים, הלוגו, וכלל הרכיבים הייחודיים —
**שייכים ב-100% לאיתי ולדמן**.

זכויות אלו מוגנות בחוק זכות יוצרים, התשס"ח-2007, ובדינים בינלאומיים רלוונטיים.

---

## 2. סוג הרישיון ללקוחות

SafeDoc מסופקת ללקוחות כ-**SaaS מותאם (white-label SaaS)**:

| פריט | אופן |
|------|------|
| מודל | Deployment נפרד (Supabase project + Vercel project) לכל לקוח |
| בעלות קוד | איתי ולדמן — לא מועברת ללקוח |
| בעלות נתונים | הלקוח — 100% |
| רישיון שימוש | רישיון לא-בלעדי, לא-מועבר, לתקופת החוזה |

---

## 4. שימוש בנתוני לקוח

- **נתוני הלקוח** (נתוני עובדים, מסמכים) — שייכים ללקוח בלבד.
- איתי ולדמן אינו רשאי לעשות שימוש בנתוני לקוח מעבר לתפעול השירות.
- בתום ההתקשרות — הלקוח זכאי לקבל את נתוניו ב-JSONL/ZIP דרך `/api/admin/export`.
- ראה גם: `docs/legal-drafts/DATA_EXPORT_AND_EXIT_CHECKLIST_HE.md`
