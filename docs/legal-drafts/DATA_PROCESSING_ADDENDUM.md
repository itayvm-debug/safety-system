# נספח עיבוד נתונים (DPA) — SafeDoc
**⚠️ DRAFT — לסקירת עורך דין בלבד | אין להשתמש כמסמך משפטי**

נספח זה הוא חלק בלתי נפרד מהסכם הפיילוט בין **נתן ולדמן ובניו בע"מ** ("עוסק בנתונים") ל**לקוח** ("בעל מאגר").

---

## 1. הגדרות

- **"מידע אישי"** — כל מידע המאפשר זיהוי אדם, כמשמעו בחוק הגנת הפרטיות, התשמ"א-1981.
- **"עיבוד"** — כל פעולה הנעשית במידע אישי.
- **"נשא המידע"** — העובד שמידע אישי שלו מעובד במערכת.

## 2. נושאי המידע ומטרות העיבוד

| קטגוריה | נושאי מידע | מטרת עיבוד |
|---------|-----------|------------|
| פרטים אישיים | עובדי הלקוח | ניהול מסמכי בטיחות |
| מסמכי זהות | עובדי הלקוח | ציות לחוק הבטיחות בעבודה |
| תמונות + חתימות | עובדי הלקוח | זיהוי ואימות; תיעוד |
| מסמכים מקצועיים | עובדי הלקוח | מעקב תוקף רישיונות |
| נתוני גישה | משתמשי המערכת | אבטחה ו-audit |

## 3. חובות העוסק בנתונים (הספק)

הספק מתחייב:
- לעבד מידע אישי אך ורק לפי הוראות הלקוח
- ליישם אמצעי אבטחה טכניים ומנהלתיים מתאימים
- שלא להעביר מידע לצדדים שלישיים ללא אישור (למעט sub-processors מאושרים)
- לסייע ללקוח במימוש זכויות נושאי המידע
- למחוק מידע בתום ההתקשרות לפי בקשת הלקוח
- להודיע ללקוח תוך TODO שעות על כל אירוע אבטחה

## 4. ספקי משנה (Sub-Processors)

הספק עושה שימוש בספקי משנה כמפורט ב-[subprocessors](/subprocessors).
השינוי ברשימת ספקי המשנה ידווח ללקוח מראש.
