## 3. תנאי הוספת ספק חדש

לפני הוספת ספק חדש שמעבד נתונים אישי:

### בדיקות מינימום
- [ ] ספק חתם על DPA (Data Processing Agreement) מתאים
- [ ] מיקום עיבוד הנתונים ידוע ותואם לחוקי הגנת פרטיות ישראל
- [ ] הספק עומד בתקנים: ISO 27001 / SOC 2 Type II (לפחות אחד)
- [ ] יש מדיניות פרטיות ציבורית ונגישה

### אישורים נדרשים
- [ ] אישור איש קשר פרטיות (itayvm@gmail.com)
- [ ] עדכון רשימת ספקי המשנה הציבורית (`/subprocessors` + `lib/legal/config.ts`)
- [ ] עדכון מדיניות פרטיות (גרסה חדשה → בדיקת חובת re-consent)

## 4. נוהל הוספת ספק

1. **הערכה** (1-3 ימים):
   - מלא טופס הערכת ספק (ראה סעיף 6)
   - בדוק עמידה בדרישות סעיף 3
   - תעד סיכונים

2. **אישור** (1 יום):
   - קבל אישור מאיש קשר פרטיות

3. **שילוב** (לפי ה-PR):
   - הוסף אינטגרציה בקוד
   - עדכן `lib/legal/config.ts` → subprocessors array
   - עדכן `/subprocessors` page (מתעדכן אוטומטית)
   - עדכן מדיניות פרטיות

4. **הודעה ללקוחות** (לפי ההסכם):
   - ב-Pilot Agreement, נדרשת הודעה 14 יום מראש לשינויי ספק מהותיים
   - שלח הודעה בדוא"ל + עדכן `CURRENT_CONSENT_VERSION` אם נדרש

---

## 5. נוהל הסרת ספק

1. ודא שאין תלות פעילה בקוד
2. ודא שכל הנתונים שנשמרו אצל הספק — הועברו/נמחקו
3. עדכן `lib/legal/config.ts`
4. הודע ללקוחות (אם רלוונטי)
