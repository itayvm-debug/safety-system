## ממצאי באגים

### B-01 — קריטי: חסרים PATCH / DELETE / GET-יחיד ב-`/api/vehicles/[id]`

**קובץ:** `app/api/vehicles/[id]/route.ts`  
**בדיקות:** V28, V29, V33, V34

**תיאור:**  
הקובץ `app/api/vehicles/[id]/route.ts` הוא העתק מילה-במילה של `app/api/vehicles/route.ts`.  
כתוצאה:

| בקשה | תגובה בפועל | תגובה צפויה |
|-------|-------------|-------------|
| `PATCH /api/vehicles/${id}` | 405 Method Not Allowed | 200 + נתוני רכב מעודכן |
| `DELETE /api/vehicles/${id}` | 405 Method Not Allowed | 200 + אישור מחיקה |
| `GET /api/vehicles/${id}` | מערך כל הרכבים של החברה | אובייקט רכב יחיד |

**השפעות:**
- עריכת רכב: ה-`VehicleForm` שולח `PATCH → 405` → `.res.json()` נזרק (body לא-JSON) → `catch` → הצגת "שגיאת תקשורת — נסה שנית" (V29)
- ארכיון רכב: `VehicleDetail.handleDelete` שולח `PATCH → 405` → `res.ok === false` → אין ניתוב, אין הודעה, כשל שקט (V33)
- GET יחיד: מחזיר מערך כל הרכבים במקום הרכב המבוקש (V34)

**ראיות מבדיקות:**
```
V28: PATCH /api/vehicles/${id} → 405  ✓ (מאמת נוכחות באג)
V29: שליחת טופס עריכה → "שגיאת תקשורת" ✓
V33: אישור ארכיון → רכב עדיין קיים ברשימה ✓
V34: GET /api/vehicles/${id} → מערך (לא אובייקט יחיד) ✓
```

### B-02 — גבוה: כשל ארכיון שקט — אין הודעת שגיאה

**קובץ:** `components/vehicles/VehicleDetail.tsx` — פונקציה `handleDelete`  
**שורות רלוונטיות:** 51–62  
**בדיקה:** V33

**תיאור:**  
כאשר המשתמש מאשר ארכיון ומקבל 405, `res.ok` שלילי אך הרכיב לא מציג שגיאה:

```typescript
// VehicleDetail.tsx — handleDelete
if (res.ok) { router.push('/vehicles'); router.refresh(); }
// else: לא קורה דבר — אין הודעת שגיאה
```

**חוויית משתמש בפועל:**  
המשתמש לוחץ "העבר לארכיון", מאשר בדיאלוג, הכפתור מציג "מעביר לארכיון..." ואז חוזר ל"העבר לארכיון" — הרכב נשאר בדף ובמסד הנתונים ללא כל הסבר.

**ראיה מבדיקה:**
```
V33: לאחר אישור ארכיון, רכב עדיין מופיע ב-/vehicles ✓
```

**שורה:** 52

כפתור "העבר לארכיון" מפעיל דיאלוג נייטיב של הדפדפן:

**ראיה מבדיקה:**

## ממצאים אינפורמטיביים (לא באגים)

### I-01: סטטוס "פג תוקף" דורש קובץ מועלה

**בדיקה:** V48  
**תיאור:**  
`getDocumentStatus(null, pastDate, true, true)` מחזיר `'missing'` (לא `'expired'`).  
ביטוח עם תאריך תוקף עבר ללא קובץ מועלה מציג "חסר" — לא "פג תוקף".  
**זהו התנהגות מעוצבת** לפי הלוגיקה ב-`lib/documents/status.ts` (שורה 42: `if (!fileUrl) return 'missing'`).  
בדיקה V48 תוקנה להתאמה לנתיב הקוד הנכון.

### I-02: לשוניות סינון סטטוס — "לא תקין" (לא "דחוף")

**בדיקות:** V53, V54  
**תיאור:**  
`StatusFilterTabs` מרנדר: **הכל** | **לא תקין** | **עומד לפוג** | **תקין**.  
"לא תקין" (ערך `'expired'`) מכיל גם `expired` וגם `missing` (הן חסר והן פג-תוקף מסווגים כ"לא תקין").  
אין לשונית "דחוף" — ממצא זה תיקן את הבדיקות V53 ו-V54.
