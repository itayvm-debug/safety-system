## 3. נוהל סקירת משתמשים

### שלב 1: ייצוא רשימת משתמשים
```
GET /api/admin/users → רשימת כל הפרופילים
```
בדוק: full_name, username, role, is_active, created_at

### שלב 2: אימות מול רשימת עובדים פעילים
לכל משתמש עם `is_active: true`, ודא:
- [ ] העובד עדיין מועסק בחברה
- [ ] ההרשאה (admin/user) מתאימה לתפקידו הנוכחי
- [ ] לא נרשמה פעילות חשודה ב-audit_logs

### שלב 3: פעולות נדרשות

| מצב | פעולה |
|-----|--------|
| עובד סיים עבודה | `PATCH /api/admin/users/:id` עם `is_active: false` |
| שינוי תפקיד | עדכן role מ-admin ל-user / להפך |
| חשבון לא פעיל 6+ חודשים | ממש לסגור או לאשר בכוונה |

### שלב 4: תיעוד
- [ ] רשום את תאריך הסקירה ב-לוג הסקירות (ראה סעיף 5)
- [ ] תעד כל שינוי שבוצע
