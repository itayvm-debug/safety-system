# רשימת מסירה ללקוח — SafeDoc
> להשלמה עם הלקוח לאחר ההקמה

## מסמכים למסירה

- [ ] קישור למערכת (URL)
- [ ] שם משתמש וסיסמה ל-admin ראשוני
- [ ] מדריך משתמש קצר (אם קיים)
- [ ] עותק של: תנאי שימוש, מדיניות פרטיות, הסכם Pilot
- [ ] `DATA_EXPORT_AND_EXIT_CHECKLIST_HE.md` — הסבר על יציאה
- [ ] `EMPLOYEE_PRIVACY_NOTICE_TEMPLATE_HE.md` — לשלוח לעובדים

## הדרכה ראשונית

- [ ] הוצג ממשק הניהול (admin dashboard)
- [ ] הוסבר כיצד להוסיף עובד
- [ ] הוסבר כיצד להעלות מסמך
- [ ] הוסבר ממשק הדוחות
- [ ] הוסבר נוהל מחיקת / ארכוב עובד שסיים

## אישורי לקוח

- [ ] לקוח אישר קבלת גישה
- [ ] לקוח אישר שקרא את תנאי השימוש
- [ ] לקוח אישר מדיניות פרטיות לעובדים (EMPLOYEE_PRIVACY_NOTICE_TEMPLATE)
- [ ] לקוח ביצע כניסה ראשונה בהצלחה
