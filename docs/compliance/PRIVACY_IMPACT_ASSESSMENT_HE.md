## 1. מטרת המסמך

מסמך זה מעריך את הסיכונים לפרטיות הנובעים ממערכת SafeDoc ומפרט את אמצעי ההפחתה שננקטו.

| פריט | פרטים |
|------|--------|
| מערכת | SafeDoc — ניהול בטיחות עובדים |
| תכלית | ניהול מסמכי זהות, רישיונות ובטיחות לעובדי קבלן |

## 4. הערכת סיכונים

### 4.1 גישה לא מורשית לנתוני עובדים

| גורם | תיאור |
|------|--------|
| **הסיכון** | גורם לא מורשה מקבל גישה לנתוני זהות עובדים |
| **הסתברות** | נמוכה — גישה רק למשתמשים רשומים, HMAC session |
| **חומרה** | גבוהה — חשיפת ת"ז, דרכונים, תמונות |
| **ניהול** | requireAuth/requireAdmin, audit logs, httpOnly cookies |
| **סיכון שיורי** | נמוך-בינוני |

### 4.2 דליפת קבצים מאחסון

| גורם | תיאור |
|------|--------|
| **הסיכון** | קישורים לקבצים חשופים ללא הרשאה |
| **הסתברות** | נמוכה — Signed URLs עם תוקף שעה |
| **חומרה** | גבוהה — מסמכי זהות |
| **ניהול** | Signed URLs בלבד, bucket פרטי, requireAuth בפני כל URL |
| **סיכון שיורי** | נמוך |

### 4.3 שיתוף נתונים עם ספק עיבוד

| גורם | תיאור |
|------|--------|
| **הסיכון** | Supabase/Vercel ניגשים לנתונים |
| **הסתברות** | בינונית — נתונים שמורים בתשתיתם |
| **חומרה** | בינונית |
| **ניהול** | DPA חתום עם Supabase ו-Vercel, הצפנה בשרת |
| **סיכון שיורי** | נמוך-בינוני |

### 4.4 כשל בגיבוי

| גורם | תיאור |
|------|--------|
| **הסיכון** | אובדן נתונים בשל כשל ב-DB |
| **הסתברות** | נמוכה — Supabase Pro עם PITR |
| **חומרה** | גבוהה |
| **ניהול** | Supabase Pro PITR + גיבוי ידני שבועי |
| **סיכון שיורי** | נמוך |

### 4.5 Rate limiting לא-גלובלי

| גורם | תיאור |
|------|--------|
| **הסיכון** | Brute-force על login בפריסה multi-instance |
| **הסתברות** | בינונית — in-memory rate limiting |
| **חומרה** | גבוהה — access token |
| **ניהול** | Rate limit per-instance קיים; MFA — בתכנון |
| **סיכון שיורי** | בינוני (מתועד ב-KNOWN_LIMITATIONS) |

## 5. סיכום סיכונים שיוריים

| סיכון | רמה | פעולה נדרשת |
|-------|-----|-------------|
| Rate limiting לא-גלובלי | בינוני | שדרוג Supabase-based rate limit בגרסה הבאה |
| העדר MFA | בינוני | תיעוד ב-MFA_IMPLEMENTATION_STATUS_HE.md |
| חובת רישום מאגר | לא ידוע | ייעוץ משפטי לפני מסחור מלא |
| DPA עם ספקים | בינוני | לאמת חתימה על DPA עם Supabase ו-Vercel |
