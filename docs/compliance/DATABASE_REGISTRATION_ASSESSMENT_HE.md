# הערכת חובת רישום מאגר מידע — SafeDoc
> תאריך: 2026-07-18 | גרסה: 1.0 | סיווג: פנימי

## 1. רקע

חוק הגנת הפרטיות, התשמ"א-1981, ותקנות הגנת הפרטיות (תנאי החזקת מידע ושמירתו וסדרי העברת מידע בין גופים), התשמ"ו-1986, מחייבים רישום מאגרי מידע המכילים מידע אישי מסוגים מסוימים.

**חשוב:** הרגולציה הישראלית בנושא מאגרי מידע עוברת שינויים — יש לבדוק עם עורך דין את חובת הרישום לפני הפעלה מסחרית מלאה.

## 3. ניתוח חובת הרישום

### 3.1 קריטריונים לרישום חובה (לפי תקנות 1986, תיקון 2017)
- [ ] מאגר הכולל מידע רגיש (בריאות, עברון פלילי, נטיות מיניות) — **לא חל**
- [ ] מאגר הכולל מידע על יותר מ-10,000 אנשים — **לא חל (single-tenant MVP)**
- [ ] מאגר המשמש לשיווק ישיר — **לא חל**
- [ ] מאגר של גוף ציבורי — **לא חל**
- [x] מאגר המכיל מספר תעודת זהות + שם — **עשוי לחייב רישום**
- [x] מאגר המכיל תמונות פנים — **עשוי לחייב רישום**

### 3.2 מסקנה ראשונית
המאגר מכיל שם + מספר זהות + תמונה של עובדים — שילוב זה **עשוי להצריך רישום**.
חובת הרישום תלויה בגודל המאגר, בסיווג העסקי של המפעיל, ובנסיבות נוספות.

## 4. פעולות נדרשות לפני מסחור מלא

1. **להתייעץ עם עורך דין** הבקיא בחוק הגנת הפרטיות הישראלי
2. **לבדוק** אם הסף הנוכחי מחייב רישום
3. **במידה ונדרש רישום** — להגיש בקשה לרשות להגנת הפרטיות דרך https://www.gov.il/he/departments/legalInfo/ppb_database_registration
4. **לתעד** את הנושא ואת החלטת עורך הדין בתיק המשפטי
