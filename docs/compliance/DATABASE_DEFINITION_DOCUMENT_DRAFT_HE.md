## 3. קטגוריות מידע

### 3.1 מידע אישי של עובדים

| שדה | סוג מידע | האם רגיש? |
|-----|---------|-----------|
| שם מלא | מזהה אישי | לא |
| מספר תעודת זהות | מזהה אישי רגיש | כן |
| מספר דרכון | מזהה אישי רגיש | כן |
| לאום / סוג עובד (ישראלי/זר) | מידע על מצב אישי | כן (מעמד הגירה) |
| תמונת פנים | ביומטרי אפשרי | **כן — טעון בחינה** |
| חתימה דיגיטלית | ביומטרי אפשרי | **כן — טעון בחינה** |
| מספר טלפון (אופציונלי) | פרטי קשר | לא |
| הערות | שדה חופשי | **אפשרי — עלול להכיל מידע רגיש** |

### 3.2 מסמכים ותעודות

| שדה | סוג מידע |
|-----|---------|
| תעודת זהות / דרכון (סריקה) | מזהה רשמי |
| אשרת עבודה | מידע הגירה |
| היתר עבודה בגובה | מסמך מקצועי |
| תדרוכי בטיחות | תיעוד הכשרה |
| מסמכים כלליים נוספים | תיעוד תפעולי |

### 3.3 מידע על משתמשי המערכת

| שדה | סוג מידע |
|-----|---------|
| שם מלא | מזהה אישי |
| מספר טלפון (לזיהוי) | פרטי קשר |
| דואר אלקטרוני (אופציונלי) | פרטי קשר |
| תפקיד במערכת (admin/user) | מידע ארגוני |

### 3.4 מידע תפעולי (לא PII)

- פרטי כלי רכב (לוחית רישוי, סוג, שם)
- פרטי ציוד כבד (תיאור, מספר)
- פרטי ציוד הרמה
- פגישות ותדרוכים

### 3.5 נתונים טכניים

- כתובות IP של משתמשים
- נתוני session (כניסה / יציאה)
- יומן ביקורת (audit_logs): פעולות משתמשים, כניסות, הסכמות
